# CoroutinesLab

A small Kotlin/JVM console project with five coroutine exercises.

## Run

Run `MainKt` from IntelliJ IDEA, or use Gradle:

```bash
./gradlew run
```

The project uses `kotlinx-coroutines-core` version 1.10.2. If the Gradle wrapper is not present, open the folder in IntelliJ IDEA and let it import the Gradle project, or generate the wrapper with `gradle wrapper`.
